# Duverger Macarons — Inventory

A small React app for logging inbound case scans and outbound sales
against a Supabase (Postgres) backend.

## Setup

1. `npm install`
2. `npm run dev` (local testing) or push to GitHub and deploy on Vercel
3. On first load, enter your Supabase Project URL and anon/publishable
   key in the Settings panel — these are stored in your browser only.
